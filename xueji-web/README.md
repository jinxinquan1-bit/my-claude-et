# 学迹 · xueji-web

学生学习记录与成长档案工具（V1.0）—— 30 秒完成一次记录，自动沉淀为成长档案，一键生成学习报告分享给家长。

> 产品需求文档：[../001-产品PRD/学生学习管理产品PRD.md](../001-产品PRD/学生学习管理产品PRD.md)

## 快速开始

```bash
npm install
npm start
```

打开 http://localhost:3000 即可使用（手机与电脑同一 WiFi 时，手机浏览器访问 `http://电脑IP:3000` 也可用，已按手机浏览器体验优化）。

- 首次使用：点击「立即注册」，用户名（2~20 位中文/英文/数字/下划线）+ 密码（≥6 位）注册后自动登录
- 数据保存在本地 `data/data.db`（SQLite 单文件，备份此文件即可备份全部数据）

## 功能清单（PRD V1.0）

| 模块 | 说明 |
| --- | --- |
| 账号 | 用户名 + 密码注册/登录，登录态 30 天；家长**免登录** |
| 学生管理 | 添加/编辑/删除（软删除）、姓名搜索、状态（在读/停课/结课） |
| 每日学习记录（核心） | 30 秒原则：日期/科目/专注度默认值友好、全部选填、**按上次记录填充**、**草稿自动暂存**（误关不丢）、支持历史补记 |
| 学生档案 | 信息卡 + 本月统计（次数/作业完成率/平均专注度）+ 记录时间线 |
| 统计 | 全局概览 + 学生维度：专注度趋势折线、作业完成率环图、知识点掌握度条形图；本周/本月/自定义 |
| 学习报告与分享 | 选学生 + 时间范围 + 老师寄语 → **快照**报告（之后改记录不影响已发报告）→ 分享链接（7 天有效、可撤销、可重新生成）→ 家长微信打开 `/r/xxx` 免登录查看 |

V1.1 规划（未实现）：照片上传、记录提醒、Excel 导入导出、报告长图导出 —— 见 PRD 第 9 章。

## 技术栈

- **后端**：Node.js ≥ 22.5 + Express + SQLite（Node 内置 `node:sqlite`，零原生编译依赖）
- **前端**：原生 HTML/CSS/JS（ES Modules，无构建步骤），Mobile-first 单页应用（hash 路由）
- **图表**：手写轻量 SVG（无第三方库），色板经色盲/对比度校验
- **安全**：bcrypt 密码加密、会话/分享 token 随机不可枚举、用户内容 HTML 转义

## 目录结构

```
xueji-web/
├── server/
│   ├── index.js          # 入口：静态资源 + /api 路由 + /r/:token 家长公开页
│   ├── db.js             # SQLite 初始化与建表（6 张表）
│   ├── auth.js           # 注册/登录/登出 + 认证中间件
│   ├── util.js           # 时间工具
│   └── routes/           # students / records / stats / reports（快照 + 分享）
├── public/
│   ├── index.html        # SPA 壳（底部 Tab：首页/学生/记一笔/统计/我的）
│   ├── share.html        # 家长报告页（免登录只读）
│   ├── css/app.css       # 设计 Token（PRD 第 6 章配色，:root 变量）
│   └── js/               # api / router / components / charts + pages/*
├── e2e-test.js           # 端到端测试（19 项断言，开发用；会写入测试数据）
└── package.json
```
